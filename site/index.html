Volpes-Media apps for Ubuntu, Zorin, Mint and Debian

Install Theatre, TvCast and BitTrader with apt, and get every new version through your usual updates.

Works on Zorin OS 18, Ubuntu 24.04 or newer, Linux Mint 22 or newer and Debian 13 or newer (64-bit PCs).

Add the repository (once)

sudo install -d -m 0755 /etc/apt/keyrings
sudo wget -qO /etc/apt/keyrings/volpesmedia.gpg https://volpesmedia.github.io/apt/volpesmedia.gpg
sudo wget -qO /etc/apt/sources.list.d/volpesmedia.sources https://volpesmedia.github.io/apt/volpesmedia.sources
sudo apt update

Install the apps

sudo apt install theatre tvcast bittrader

Pick only the ones you want. Updates arrive with sudo apt upgrade or the Software Updater.

Remove the repository

sudo rm /etc/apt/sources.list.d/volpesmedia.sources /etc/apt/keyrings/volpesmedia.gpg
sudo apt update
